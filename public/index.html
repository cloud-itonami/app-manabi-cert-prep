今日もよろしく

ようこそ。これは manabi (学び) の cert_prep サブセル — CISA / CISSP の CBK domain を、自分のペースで学ぶための substrate です。

このアプリの 6 つの約束

  • credential は発行しません (CISA / CISSP は外部の credentialing body が発行するもの)
  • 合格率は予測しません
  • streak / leaderboard / badge / XP は存在しません
  • 公式の過去問は再現しません — 練習問題は概念から合成 (R1+) または各自で持ち込み (R2+)
  • あなたの学習履歴はあなた本人だけが読めます (R1+ で暗号化保存; W1 はこの端末の localStorage のみ)
  • LLM 支援は Murakumo fleet 経由のみ (R1+); 商用 GPU 借りは使いません

何を学ぶか

CISA を続ける CISSP を続ける domain 一覧を見る

このアプリは何ではないか

  • 合格保証ツールではありません (N11)
  • ISACA / (ISC)² / SANS / EC-Council / CompTIA / Offensive Security とは partnership がありません (G17 + N12)
  • religious-corp 内部の steward 役職への gate ではありません — 能力は domainMasteryAttestation (subject-specific demonstration) で判断されます、外部 credential 所持ではなく (N13)
R0 scaffold — このアプリは現在 W0+W1 (静的 UI のみ; LLM 支援なし)。 R1 (LLM + 暗号化履歴) は Council Lv6+ ≥3 が ADR-2605264400 を ratify した後に有効化されます。
