CBK domain 一覧

順番に学んでも、興味のある domain から始めても構いません。完了率 (%) を表示しないのは、 "あと N% で完了" という engagement-bait を避けるためです (G3)。 各 domain の 触れた concept 数は 履歴 で確認できます。

CISA — IT audit (5 domains)

  • Domain 1 — Information Systems Auditing Process
    audit planning / execution / reporting / evidence — ISO 19011 + ISACA framework concepts
  • Domain 2 — Governance and Management of IT
    governance frameworks / risk-based audit — COBIT 2019 conceptual + ISO 38500
  • Domain 3 — Information Systems Acquisition, Development & Implementation
    SDLC controls / project audit / change management — NIST SP 800-160
  • Domain 4 — Information Systems Operations and Business Resilience
    operations controls / BCP/DR — ISO 22301 conceptual + NIST SP 800-34
  • Domain 5 — Protection of Information Assets
    access control / cryptography / data classification — NIST SP 800-53 + ISO 27002 conceptual

CISSP — information security (8 domains)

  • Domain 1 — Security and Risk Management
    CIA triad / risk methodology / law & regulation — GDPR / APPI / CCPA + NIST RMF
  • Domain 2 — Asset Security
    data classification / ownership / lifecycle — ISO 27002 §5 conceptual
  • Domain 3 — Security Architecture and Engineering
    secure design principles / cryptography / hardware-rooted trust — NIST SP 800-160 + FIPS 140-3
  • Domain 4 — Communication and Network Security
    OSI model concepts / protocol security / TLS / VPN — RFC + NIST SP 800-52
  • Domain 5 — Identity and Access Management
    authentication / authorization / federation — OAuth 2.0 / OIDC / SAML concepts
  • Domain 6 — Security Assessment and Testing
    vulnerability mgmt / pentesting concepts / code review — NIST SP 800-115
  • Domain 7 — Security Operations
    incident response / forensics concepts / monitoring — NIST SP 800-61
  • Domain 8 — Software Development Security
    secure SDLC / OWASP Top 10 concepts / supply chain — NIST SSDF
Domain の章立て構造は ISACA / (ISC)² が公式に公開している outline を参照しています (outline の 構造は事実情報として fair-use 範囲)。 各 domain の概念解説本体は NIST SP / ISO 27001/27002 / COBIT 2019 / GDPR / APPI などの公開仕様から構成しています — 公式 study guide や過去問の reproduction ではありません (G16)。
